# 🖥️ โปรแกรมกันจอดับ (Screen Keep-Alive)

โปรแกรมขนาดเล็กและน้ำหนักเบา ออกแบบมาเพื่อป้องกันไม่ให้หน้าจอคอมพิวเตอร์ออฟฟิศดับหรือล็อกตัวเองทุกๆ 5 นาที โดยจะทำการแอ็กชันแบบไร้เสียงรบกวนทุกๆ **4 นาที 50 วินาที** (290 วินาที) โดยไม่ส่งผลกระทบต่อการใช้งาน ไม่แย่งเมาส์ และไม่แทรกตัวอักษรใดๆ เข้าไปในงานที่คุณกำลังพิมพ์

---

## 🌟 จุดเด่นและหลักการทำงาน

1. **ไม่ส่งผลต่อการทำงาน 100% (Non-Intrusive)**
   - **Windows Power API (`SetThreadExecutionState`):** แจ้งเตือนระบบปฏิบัติการ Windows ให้คงสถานะหน้าจอเปิดอยู่เสมอ
   - **Safe Micro Mouse Pulse:** ขยับตำแหน่งเมาส์สัมพันธ์ 1 พิกเซลและดึงกลับทันทีในระดับไมโครวินาที ตำแหน่งเมาส์อยู่ที่เดิม ไม่กระตุก ไม่รบกวนการคลิก
   - **Virtual Key F15:** จำลองการกดปุ่มฟังก์ชัน F15 เสมือน เพื่อรีเซ็ตระบบจับเวลาหยุดนิ่ง (Idle Timer) ของนโยบายความปลอดภัยออฟฟิศ โดยไม่มีตัวอักษรพิมพ์ออกมา และไม่มีเสียงรบกวน
2. **ใช้งานง่ายมาก (Simple UI)**
   - ดับเบิลคลิกเปิดโปรแกรม ระบบจะเริ่มต้นทำงานให้อัตโนมัติทันที
   - มีปุ่มขนาดใหญ่ชัดเจน: **"▶ เริ่มทำงาน"** (สีเขียว) และ **"⏹ หยุดทำงาน"** (สีแดง)
   - แสดงเวลานับถอยหลังแบบเรียลไทม์ (04:50), เวลาที่แอ็กชันล่าสุด และจำนวนครั้งที่แอ็กชันไปแล้ว
   - มีปุ่ม **"⚡ ทดสอบแอ็กชันทันที"** ให้คุณสามารถทดสอบการทำงานได้ทันทีโดยไม่ต้องรอให้ครบเวลา
   - มีปุ่ม **"📌 สร้างทางลัดบน Desktop"** เพื่อสร้างไอคอนไว้บนหน้าจอเดสก์ท็อป สะดวกต่อการเปิดใช้งานทุกวัน
3. **ซ่อนทำงานที่ System Tray ได้**
   - เมื่อกดปุ่มกากบาท (X) หรือย่อหน้าต่าง โปรแกรมจะลงไปทำงานเงียบๆ ที่ System Tray (มุมขวาล่างใกล้ๆ นาฬิกา) ไม่เกะกะ Taskbar
   - คลิกขวาที่ไอคอนถาดระบบเพื่อดูเมนู เริ่ม/หยุด หรือดับเบิลคลิกเพื่อดึงหน้าต่างกลับมา
4. **พกพาสะดวกและปลอดภัย (Zero Dependency)**
   - เป็นไฟล์เดี่ยวแบบ Standalone Executable ขนาดเพียง ~16 KB
   - ใช้ .NET Framework มาตรฐานที่ติดมากับ Windows ทุกเครื่อง ไม่ต้องติดตั้ง Python หรือสิทธิ์ Admin เพิ่มเติม

## 📁 ไฟล์ภายในโฟลเดอร์ `D:\โปรแกรมกันจอดับ`

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| `โปรแกรมกันจอดับ.exe` | ตัวโปรแกรมหลัก ดับเบิลคลิกใช้งานได้ทันที |
| `ScreenKeepAlive.exe` | สำเนาตัวโปรแกรมหลัก (ชื่อภาษาอังกฤษเพื่อความสะดวก) |
| `app.ico` | ไฟล์ไอคอนจอคอมพิวเตอร์สีเขียวประจำโปรแกรม |
| `Program.cs` | โค้ดต้นฉบับภาษา C# พร้อมคอมเมนต์ภาษาไทยอย่างละเอียด |
| `build.bat` | ไฟล์สคริปต์คอมไพล์โปรแกรมใหม่ได้ด้วยคลิกเดียว |
| `README.md` | เอกสารคู่มือการใช้งานฉบับนี้ |

---

## 🚀 วิธีใช้งาน

1. ไปที่ `D:\โปรแกรมกันจอดับ`
2. ดับเบิลคลิกที่ไฟล์ **`โปรแกรมกันจอดับ.exe`** (หรือไอคอนทางลัดบน Desktop)
3. เมื่อเปิดขึ้นมา โปรแกรมจะขึ้นสถานะ **🟢 กำลังทำงาน (ระบบกันจอดับเปิดอยู่)** โดยอัตโนมัติ
4. คุณสามารถทำงานได้ตามปกติ หน้าจอจะไม่ดับและเครื่องจะไม่พักหน้าจอ
5. เมื่อเลิกงานหรือต้องการให้หน้าจอดับตามปกติ ให้กดปุ่ม **"⏹ หยุดทำงาน"** หรือคลิกขวาที่ไอคอนมุมขวาล่างแล้วเลือก **"ปิดโปรแกรมอย่างสมบูรณ์"**

---

## 🛠️ การแก้ไขและคอมไพล์ใหม่ (หากต้องการปรับแต่ง)

หากต้องการปรับแต่งระยะเวลารอบการทำงาน สามารถเปิดไฟล์ `Program.cs` แล้วแก้ไขค่า:
```csharp
private const int CYCLE_SECONDS = 290; // แก้ไขจำนวนวินาทีที่ต้องการ (290 วินาที = 4 นาที 50 วินาที)
```
จากนั้นดับเบิลคลิกที่ไฟล์ **`build.bat`** เพื่อคอมไพล์ใหม่ได้ทันที
